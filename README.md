# UTS Pemweb 2 - CR Mahasiswa
Dibuat oleh: Anas Sudarja

## Deskripsi
Project ini adalah sistem data mahasiswa sederhana dengan fitur CR (Create & Read) saja, tanpa Update & Delete, sesuai instruksi tugas.

Fitur:
- Create: Menambah data mahasiswa baru (tambah.php)
- Read: Menampilkan semua data mahasiswa (index.php)

## Struktur File
- koneksi.php -> koneksi database
- index.php -> tampil data
- tambah.php -> tambah data

## Cara Menjalankan di Localhost
1. Clone / download repo ini
2. Taruh folder di C:/xampp/htdocs/
3. Buat database di phpMyAdmin dengan nama uts_pemweb2
4. Buat tabel mahasiswa (nim, nama, jurusan, alamat)
5. Jalanin XAMPP Apache & MySQL
6. Buka browser: localhost/uts_pemweb2/
